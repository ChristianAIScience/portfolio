Selected Projects

RAG Learning Lab

A hands-on project covering the retrieval-augmented generation workflow end to end: document ingestion with font-size-based PDF chunking into PostgreSQL/pgvector, five retrieval strategies including hybrid keyword + vector search with Reciprocal Rank Fusion, and the same pipeline built as a LangChain chain, a LangGraph graph, and an agentic graph that grades results and rewrites queries. Retrieval quality is measured with Hit@k/MRR and LLM-as-a-judge, and runs are tracked in MLflow.

Document Classification Agent

A pipeline that turns German quote and invoice PDFs into validated database records: Docling conversion with OCR, rule-based classification with confidence scoring, LLM extraction into Pydantic schemas via structured output, and Decimal-based checks of totals and VAT. Results are stored in PostgreSQL (SQLAlchemy, Alembic) and exposed through a FastAPI REST API, including deterministic detection of differences between a quote and its invoice. Extraction and deviation detection are evaluated in MLflow on a 50-pair ground-truth test set created with the Synthetic Quote & Invoice Generator.

Synthetic Quote & Invoice Generator

A generator for fictional German quotes and invoices as PDFs (ReportLab), built to produce evaluation data for the Document Classification Agent. It creates reproducible quote/invoice pairs with JSON ground truth and deliberately puts exactly one difference into 30 % of the invoices. An optional OpenAI extension generates new sender and job data via JSON-schema output, which is validated before use.
